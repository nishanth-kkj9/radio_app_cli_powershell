# Support

## Start here

1. Read the [README](README.md).
2. Check the [troubleshooting guide](docs/TROUBLESHOOTING.md).
3. Run `python -m radio_ps --check` or `Start-Radio.ps1 -Check`.
4. Inspect `log 100` for runtime failures.

## Bug reports

Use the repository's bug-report template and include:

- Windows version
- Python version
- VLC version and architecture
- terminal application
- PowerShell version
- application version (`radio --version`)
- exact command or interaction that fails
- relevant log output with sensitive data removed
- minimal reproduction steps

Do not include passwords, tokens, private URLs, or personal data.

## Feature requests

Use the feature-request template. Explain the user problem first, then the proposed behavior. For terminal/UI features, describe the expected behavior on both Windows Terminal and compatibility terminals when relevant.

## Questions

For configuration and usage questions, check the documentation before opening an issue. Issues should remain focused on actionable project problems and improvements.
