# Code of Conduct

## Our standard

PowerShell Radio Pro aims to be a constructive, technical, and respectful open-source project. Participants are expected to communicate professionally, assume good faith, and focus criticism on code and ideas rather than people.

Unacceptable behavior includes harassment, personal attacks, discrimination, threats, deliberate disruption, publishing private information, and other conduct that makes participation unsafe or hostile.

## Maintainer action

Maintainers may remove or reject contributions that violate these standards and may restrict participation when necessary to keep the project constructive.

## Reporting

For conduct concerns, contact the repository maintainer privately through GitHub. For security vulnerabilities, follow [`SECURITY.md`](SECURITY.md) instead of using a public issue.
